Docs

Install

  • Download the installer from the download section, or run irm https://repousiosjim.github.io/beatforge-site/install.ps1 | iex in PowerShell.
  • Windows 10/11 x64. Per-user install, no admin. SmartScreen warns because the build is unsigned: choose More info → Run anyway.
  • Updates: BeatForge checks once at launch. Settings → Updates has Check, Download, Restart to update.

First beat

  • Tracks lists your tracks. Drum tracks open in the bottom Detail region's Clip mode as a Sequencer: click steps to toggle; velocity in the lane below the grid.
  • Instrument tracks open in Clip mode as a MIDI Clip editor: click to add a note, drag to move, right edge to resize, Alt-drag to duplicate, B for draw mode, velocity in the lane below the grid. Audio clips open as an Audio Clip editor; Device mode shows the track's device chain.
  • Patterns: the Pattern menu in the top bar adds, duplicates, renames, and sets bar length. Arrangement lays out patterns and audio on one timeline.
  • Space plays and stops. The Pattern / Arrangement switch chooses what plays.

Piano roll

  • Range A0–C8. PageUp / PageDown scroll an octave. Ctrl+wheel zooms; Follow keeps the playhead in view.
  • Toolbar: Quantize, Humanize, Chord stamp, Length, Transform (transpose, invert, reverse), Ghost track.
  • Select with marquee or click; Shift adds. Ctrl+C / Ctrl+V / Ctrl+D copy, paste, duplicate.
  • MIDI in: with a keyboard connected, toggle MIDI in. Stopped: step entry at the cursor. Playing: live record.

Mixer, effects, automation

  • Each strip: volume, pan, EQ3, compressor, devices (reverb, delay, chorus, distortion, multiband), sends to return tracks.
  • Automation tab: lanes for track volume, pan, device parameters and the Main. Draw points, set curves; playback and export honor them.
  • Recording: pick an input in Settings → Audio input, arm, record; clips land on an audio track and can be trimmed, split, faded.

AI assistant

  • Bring your own OpenRouter key in Settings. Pick a model per feature, set budgets, see cost per call.
  • Features: drum pattern, melody, mix suggestion, sample pick. Audition before you apply; every apply is undoable.

Export and files

  • Ctrl+Shift+E exports WAV, MP3 or MIDI. What you hear is what renders.
  • Projects are .bfp files. Recorded and imported audio lives beside them in a .beatforge-audio folder; autosave keeps three recovery slots in .beatforge-recovery. Move the folder with the file.

Shortcuts

  • Space play / stop · Ctrl+S save · Ctrl+Shift+S save as · Ctrl+O open · Ctrl+N new · Ctrl+Shift+E export · Ctrl+, settings
  • Ctrl+Z undo · Ctrl+Y / Ctrl+Shift+Z redo
  • Ctrl+Alt+B browser · Ctrl+Alt+D detail · Ctrl+Alt+M mixer · Ctrl+Alt+A AI assistant
  • Piano roll: Ctrl+A select all · Ctrl+C/V/D copy, paste, duplicate · Delete · Ctrl+Q quantize · Ctrl+H humanize · Shift+↑/↓ transpose semitone · Ctrl+Shift+↑/↓ octave · PageUp/PageDown scroll octave · Esc deselect
  • Shift+Tab Clip / Device detail · Ctrl+F Browser search · double-click the Detail header to maximize
  • Arrangement: Alt-drag duplicate · Ctrl+D duplicate clip · Ctrl+E split audio clip · Ctrl+L loop to clip · Ctrl+Alt+L loop end auto · Home/End · ↑/↓ track · Enter open clip · Alt-click fold all
  • Tracks: Ctrl+T audio · Ctrl+Shift+T instrument · Ctrl+Alt+T return · Ctrl+R rename · Delete remove
  • Piano roll grid: B draw · Ctrl+1/2 grid · Ctrl+4 snap. Numeric controls: double-click resets, drag the value to adjust.
