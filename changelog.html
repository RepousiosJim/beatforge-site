Changelog

0.2.5 — recording and metering

2026-09-04

  • Metronome count-in before recording: Settings → Audio, Off / 1 bar / 2 bars. Press record again during the count-in to cancel.
  • Automation paste creates the lane when the pattern has none; Ctrl+C / Ctrl+V on the Automation tab.
  • Phase correlation meter on the Main strip.

0.2.4 — reliability

2026-09-04

  • Undo fully restores removed tracks (their automation, sends and every pattern), removed devices, and the order of removed notes.
  • Clear error message when a project file cannot be opened.
  • Under the hood: user-journey tests drive the real app (make a beat, write a melody, arrange and export, save and reopen) and a generic undo/redo check covers every command.

0.2.3 — quality of life

2026-09-04

  • Alt-drag duplicates notes and clips; B toggles draw mode; Ctrl+1/2 grid, Ctrl+4 snap.
  • Ctrl+D / Ctrl+E / Ctrl+L on arrangement clips; Home/End seek; arrow keys select tracks; Enter opens the clip.
  • Ctrl+T / Ctrl+Shift+T / Ctrl+Alt+T add tracks; Ctrl+R renames; Delete removes (undo restores every pattern).
  • Double-click resets faders, pans, sends and device values; drag the readout to adjust. Double-click the Detail header to maximize it.

0.2.2 — review fixes

2026-09-03

  • Arrangement shows a lane per track with miniature pattern content; clips move together.
  • Mixer faders fill the strip; readable section markers; stacked LUFS on Main.
  • Detail region opens taller; piano roll toolbar no longer wraps; flat device chain.
  • Settings column bounded; Pattern | Song mode chip; distinct track colours.

0.2.1 — Ableton-familiar interface

2026-09-03

  • Control Bar regrouped: timing, transport, loop, pattern, view and panel toggles; Info strip with hover help and selection context.
  • Flat surfaces everywhere: one-pixel dividers, no cards, glows or gradients.
  • Arrangement with track headers: colour, rename, mute, solo, fold.
  • Detail region with Clip and Device modes; editors open from the selected track; device chain shared with the mixer.
  • Dense flat mixer with Returns and Main; full-window Settings pane.
  • Vocabulary: Arrangement, Tracks, Devices, Returns, Main. Shift+Tab switches Clip/Device, Ctrl+F focuses the Browser search.

0.2.0 — v2 plans closed

2026-09-03

  • Automation: one-click volume lane per track, overlay of all lanes, copy / paste / duplicate lanes, values snap back when you stop.
  • Mixer: rename strips inline, sidechain ducking on the compressor, colour per track, LUFS and spectrum on the master.
  • Browser: full-text search, tag filters, waveform preview with play, favorites.
  • Transport: metronome and tap tempo.
  • MIDI: map any CC to track volume, pan or master with Learn.
  • Help → Documentation opens the docs page.

0.1.3 — piano roll

2026-09-03

  • Full A0–C8 range with octave lines; PageUp/PageDown scroll by octave.
  • Horizontal zoom (Ctrl+wheel or toolbar) and follow-playhead.
  • Velocity lane: drag bars, multi-select moves together, paint with Ctrl.
  • Notes sound when clicked or dragged; resize many notes at once.
  • MIDI keyboard input: step entry when stopped, live record when playing.

0.1.2 — installer and updates

2026-09-03

  • Branded installer with license page; launches the app when done.
  • .bfp project files open in BeatForge on double-click; one instance only.
  • Uninstaller asks before deleting settings; projects are never touched.
  • Updates install silently and relaunch. The app checks once at launch and shows a notice.
  • One-line terminal install: irm https://repousiosjim.github.io/beatforge-site/install.ps1 | iex

0.1.0 — first public build

2026

  • Step sequencer with channel rack, and a piano roll with quantize, humanize, and chord entry.
  • Playlist/arrangement view mixing pattern and audio clips on one timeline.
  • Full mixer: EQ, compressor, reverb, delay, chorus, distortion, multiband, sends and buses.
  • Automation lanes for any parameter, plus audio recording and non-destructive WAV import (trim, split, fade, gain).
  • WAV, MP3, and MIDI export with live/export parity.
  • AI assistant for drum patterns, melodies, mix suggestions and sample picking, on your own OpenRouter key, with per-feature model choice, cost tracking and budgets.
  • Experimental VST3 instrument scanning and audition on Windows.
  • Forge Dark and Forge Studio themes, and autosave with three-slot recovery.
